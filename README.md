# CleanCanada - House & Office Cleaning Service

A fast, responsive, high-converting landing page for CleanCanada.

## Features
- **All-in-One Single File**: All styles, scripts, SVG brand icons, and 21 compressed images are inlined directly into `index.html`.
- **Zero External Asset Dependencies**: No broken image links, no separate asset folders, and zero extra HTTP requests.
- **Instant Deployment Ready**: Ready for 1-click deployment on Vercel, GitHub Pages, or Netlify.

## Project Structure
```
cleancanada/
├── index.html       # Complete self-contained website with embedded compressed images
├── vercel.json      # Minimal Vercel configuration
├── README.md        # Documentation
└── .gitignore       # Git ignore rules
```

## Deployment to Vercel
1. Push this folder to your GitHub repository.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your `cleancanada` repository.
4. Leave all settings as default (Framework Preset: **Other**).
5. Click **Deploy**.
